> Gojo puts private on-device dictation, window controls, clipboard history, file staging, media controls, and display tools one hover away in the MacBook notch.

Gojo is a native macOS utility that combines dictation, window snapping, clipboard history, a file shelf, media controls, and display warmth in the MacBook notch. Dictation runs on the Mac. Gojo supports macOS 14 and later and offers a fully unlocked three-day trial without a card.
