> A free, open-source menu bar disk cleaner for macOS that removes known-safe caches and developer build artifacts.

Dusty scans only allowlisted locations and lets you review every cleanup candidate before removing it. The native SwiftUI app can clean Xcode data, package-manager caches, Docker data, logs, and other reproducible files without telemetry or `sudo`.

Install with Homebrew or download the signed DMG from the [Dusty GitHub repository](https://github.com/yagcioglutoprak/dusty).
