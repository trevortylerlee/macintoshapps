LayoutKeeper is a free, open-source (GPL-3.0) macOS menu bar app for multi-monitor setups. It remembers where windows were on each Space, puts them back after you unplug and plug in a display, can follow USB-C port to switch arrangement presets, and can sync external-display brightness with the built-in ambient light sensor (v0.6.14). Four prevent-sleep modes are included. Apple Silicon and Intel builds are on GitHub Releases.
