Usage HUD is a native Mac menu-bar meter for Claude, Codex, Gemini, Grok, and Ollama usage windows. Every number has a confidence label and a doctor command that explains when a reading is not trustworthy. Everything stays on the Mac. No account, no telemetry.

If CodexBar already works for you, you do not need this. $9 launch price through 30 Sep 2026, then $15. Apple silicon, macOS 14+.
