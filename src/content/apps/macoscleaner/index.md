> Free native macOS cleaner built with Swift/SwiftUI. Shows everything before deletion; removed items go to Trash by default. Version 3.0.0 adds a Privacy Inspector (TCC permissions, network sockets, browser extensions). Requires macOS 26+ and Apple Silicon.

Source-available (GPLv3 + Commons Clause). DMG: https://github.com/AlexTkDev/MacOSCleaner/releases/latest/download/MacOSCleaner.dmg
