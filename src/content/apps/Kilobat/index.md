Kilobat is a macOS menu bar app for monitoring network activity and troubleshooting connections. Basic features are free, with an optional one-time Pro upgrade.

The desktop app is proprietary. A separate [Kilobat CLI](https://github.com/seifip/kilobat-cli) provides scriptable network diagnostics and an MCP server under GPL-3.0-only; some app-specific information requires the desktop app to be running.
